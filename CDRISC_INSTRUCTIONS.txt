CD-RISC 心理弹性量表（25 道题）使用说明
========================================

一、量表简介
------------
CD-RISC（Connor-Davidson Resilience Scale）是由 Connor 和 Davidson 于 2003 年开发的心理弹性评估量表，
共 25 道题，用于评估个体应对压力和逆境的能力。

二、计分方式
------------
每题采用 5 级评分：
- 从来不 = 0 分
- 很少 = 1 分
- 有时 = 2 分
- 经常 = 3 分
- 一直如此 = 4 分

总分范围：0-100 分
分数越高表示心理弹性越强，应对压力的能力越强。

三、分数解释
------------
根据常模数据（Connor & Davidson, 2003）：
- 男性平均分：80.2 ± 14.8 分
- 女性平均分：76.5 ± 15.2 分

分数段参考：
- 80-100 分：心理弹性很强，能很好地应对压力
- 60-79 分：  心理弹性较好，基本能应对大多数压力
- 40-59 分：  心理弹性一般，可能需要提升应对技能
- 0-39 分：   心理弹性较弱，建议寻求专业支持和干预

四、实施流程
------------
1. 学生登录系统后进入"心理问卷评估"页面
2. 点击"开始问卷"，填写基本信息（姓名、性别、年龄、年级）
3. 选择当前状态（干预前/干预后）
4. 完成 25 道题目的作答
5. 提交后自动跳转到"能量监测窗"查看分数
6. 所有数据自动保存到数据库

五、数据保存
------------
系统会保存以下数据：
1. 每道题的答案和分数（user_answers 表）
2. 总分和干预状态（psychological_data 表）
3. 学生基本信息快照（姓名、性别、年龄、年级）
4. 测试日期和时间戳

六、结果应用
------------
1. 干预前评估：了解学生初始心理弹性水平
2. 干预后评估：评估干预效果
3. 追踪观察：通过历史记录查看变化趋势
4. 预警功能：对低分学生进行关注和干预

七、注意事项
------------
1. 测试环境应保持安静，避免干扰
2. 指导语要清晰，确保学生理解计分方式
3. 测试结果应保密，仅用于心理健康评估
4. 低分学生应及时提供心理支持和干预
5. 定期组织测试，追踪学生心理状态变化

八、技术实现
------------
- 问卷题目和选项存储在数据库（questionnaires, questions, options 表）
- 学生答案存储在 user_answers 表
- 总分和干预状态存储在 psychological_data 表
- 支持多次测试，保留历史记录
- 自动计算总分并跳转到能量监测页面
