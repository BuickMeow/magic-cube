# 数据库脚本说明

## 文件

- `magic_cube.sql`：MySQL 建库、建表和初始化测试数据脚本。

## 导入方式

1. 确认本机已安装 MySQL 8.0 或兼容版本。
2. 使用命令行导入：

```bash
mysql -u root -p < magic_cube.sql
```

3. 导入完成后会创建数据库 `magic_cube`。

| 角色 | 用户名 | 密码 | 说明 |

## 注意事项

- 当前项目代码中密码仍为明文比对，脚本中的密码与当前实现保持一致。
- 如本地数据库已有同名表，脚本会先删除再重建，请先备份旧数据。
- 项目配置文件默认连接数据库名为 `magic_cube`。
