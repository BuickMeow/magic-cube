# “语文魔方”学生心理能量监测与教学资源管理系统部署说明

## 1. 项目简介

本系统是基于 Java Web 技术开发的综合性 Web 应用，面向语文教学和学生心理健康管理场景，提供用户登录注册、心理问卷测评、心理能量监测、教师端班级数据分析、干预记录、班级论坛、教学资源管理等功能。

当前项目采用 Spring Boot、Spring MVC、Thymeleaf、Spring Data JPA 和 MySQL 开发，运行时内置 Web 容器，可直接通过 Maven 启动。

## 3. 数据库初始化

1. 启动 MySQL 服务。
2. 打开命令行，进入项目目录：

```bash
cd C:\Users\TQTY\Desktop\magic-cube-main
```

3. 执行数据库脚本：

```bash
mysql -u root -p < submission-materials\database\magic_cube.sql
```

4. 脚本执行后会创建数据库 `magic_cube`，并初始化测试账号、问卷、教学资源、论坛和心理测评示例数据。

## 4. 修改数据库配置

项目配置文件位置：

```text
src/main/resources/application.properties
```

默认配置如下：

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/magic_cube?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
spring.datasource.username=${DB_USERNAME:root}
spring.datasource.password=${DB_PASSWORD:}
```

如果本机 MySQL 用户名或密码不同，可使用环境变量启动：

```bash
set DB_USERNAME=root
set DB_PASSWORD=你的数据库密码
mvnw.cmd spring-boot:run
```

也可以在 IDEA 的 Run Configuration 中配置环境变量：

```text
DB_USERNAME=root;DB_PASSWORD=你的数据库密码
```

## 5. AI 建议功能配置

系统中包含 AI 心理建议功能。若需要启用该功能，需要设置环境变量：

```bash

```

如果不配置 API Key，系统核心功能仍可运行，但 AI 建议接口可能返回降级提示或调用失败。

## 10. 常见问题

### 10.1 数据库连接失败

检查 MySQL 是否启动、数据库脚本是否导入、`DB_USERNAME` 和 `DB_PASSWORD` 是否正确。

### 10.2 端口被占用

修改 `src/main/resources/application.properties`：

```properties
server.port=8081
```

### 10.3 页面中文显示异常

确认数据库、连接串和浏览器均使用 UTF-8。数据库脚本已经设置为 `utf8mb4`。

### 10.4 教学资源文件无法下载

确认 `src/main/resources/static/teaching-resources` 目录下存在对应课文资源文件。数据库脚本中的资源记录与项目当前静态资源目录保持一致。
